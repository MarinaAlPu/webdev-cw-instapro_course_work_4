# Instapro

MVP социальной сети для обмена фотографиями

## Первоначальная оценка
16 часов, в т.ч. 4 часа на дополнительный функционал 

## Фактически затраченное время
28 часов, в т.ч. 8 часов на дополнительный функционал

## Реализовано:
### основной функционал:
- Интеграция верстки списка постов с API
- Страница добавления поста
- Открытие страницы с постами отдельного пользователя
- Установка и удаление лайка
- Обработка ошибок
- Обработка введённого значения (предотвращение загрузки html-кода)

### дополнительный функционал:
- Анимация при установки / снятии лайка
- Рендер кнопки "Удалить" для авторизованного пользователя только для постов этого пользователя
- Удаление поста (учитывая, что, как выяснилось, с прода удалять посты нельзя, отображается соответтвующее уведомление, пост удаляется, но после обновления страницы восстанавливается на прежнем месте)
- Отображение сообщения с именем пользователя из первого лайка в списке лайков при их наличии, и указание количества других пользователей, лайкнувших пост при наличии лайков больше 1
